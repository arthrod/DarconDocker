================================================================================
NOTES:
- All onboarding interfaces (Streamlit, CLI) use the same backend logic.
- All configs and onboarding steps are version-controlled for reproducibility.
- Orchestrator dynamically discovers and registers agents via agent card metadata.
- After agent registration, the orchestrator sends a test prompt to each new agent. The agent's response is displayed to the user, confirming the agent is live and ready for commands.
- The orchestrator then benchmarks the new agent (latency, correctness, resource usage). Results and a final 'Agent is ready' message are shown to the user upon success.
- Communication uses HTTP/JSON via standardized FastAPI /invoke endpoints for all agents/tools (generic wrapper pattern).
- Agent logic is loaded dynamically at runtime via AGENT_GRAPH_PATH for plug-in modularity.
- Agent conference graph enables all-way agent communication and aggregation.
- docker-compose.yml is the authoritative registry for all agents/tools.
- Memory bank and onboarding flows are always updated to reflect new agents and workflows.
- Minimal manual steps: user only provides secrets/keys and approves config.
