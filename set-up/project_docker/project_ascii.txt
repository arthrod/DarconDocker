Key Flows:
- User interacts with Orchestrator (UI/API)
- Orchestrator handles onboarding, agent registry, benchmarking, and memory bank
- Agents/tools are plug-ins, registered in docker-compose.yml, and run as containers
- All agents expose /invoke and /health endpoints (generic FastAPI wrapper)
- Agent Conference Graph enables robust, all-way agent communication
- Memory Bank and onboarding flows are always updated with new agents/tools
